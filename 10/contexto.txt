Critérios

O que é uma API e para que ela serve? 
R: Uma API serve pra requisitar os serviços de algum software ou serviço de outro lugar conectando com o servidor. 

O que são cliente e servidor em uma comunicação por API? 
R: Um cliente é aquele que requisita algo que no caso é a gente e o servidor aonde o site ou a API fica hospedada.

Qual é a diferença entre uma requisição e uma resposta?
R: Uma requisição faz voce perguntar pro servidor se voce pode acessar X informação e a resposta é quando ele devolve a requisição que vc fez

Para que servem os métodos HTTP GET, POST, PUT e DELETE?
R: Get é para receber os dados, POST é para pedir os dados, Put é pra colocar os dados e Delete pra deletar os dados 

O que são códigos de status HTTP? Explique o significado de 200, 404 e 500.
R: 200 é quando o HTTP aceita a requisição, 404 quando ele não é encontrado e 500 quando um erro no servidor acontece.
