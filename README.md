# 💻 Desafios de Código - Servidor Juninhos

Este repositório documenta a minha evolução e prática contínua em programação através da resolução diária de problemas propostos no servidor do Discord "Juninhos". Como estudante de Análise e Desenvolvimento de Sistemas com foco em Engenharia de Dados, utilizo esses exercícios para aprimorar minha lógica, manipulação de dados e domínio da linguagem Python.

## 🚀 Tecnologias e Foco
* **Linguagem:** Python
* **Foco Principal:** 
  * Lógica de programação
  * Manipulação de strings e tipagem de dados
  * Estruturas de dados (listas e dicionários)
  * Algoritmos de busca e ordenação
  * Estruturas condicionais e laços de repetição (`for`, `while`, `if`, `elif`, `else`)

## 🧠 Aprendizados e Habilidades Aplicadas

Ao longo da resolução destes problemas, venho consolidando conceitos essenciais para o desenvolvimento de software e análise de dados, como:
* **Validação de Dados:** Prevenção de campos vazios, tratamento de exceções e garantia de integridade das informações inseridas.
* **Controle de Fluxo:** Implementação de lógicas de iteração e decisão para resolver problemas algorítmicos.
* **Manipulação e Limpeza:** Normalização de entradas do usuário, conversão de tipos de dados e formatação de saídas para melhor legibilidade.
* **Modelagem de Soluções:** Uso de dicionários e listas para estruturar informações de forma organizada, simulando pequenos sistemas (como agendas e analisadores de texto).
